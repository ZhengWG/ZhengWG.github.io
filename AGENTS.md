# Repository instructions

## Terminal UI language

Use English for prompts or commands submitted through Termius or another terminal UI. Reply to the user in Chinese unless they request otherwise.

## Cross-platform publishing

Read `docs/syndication-policy.md` before exporting, submitting, or updating articles on Zhihu, CSDN, Juejin, or Xiaohongshu. Put public blog navigation and the matching original article link at the beginning of the article or note description. Never include private source-note links. Update existing platform IDs when available and record draft, review, published, and quota-blocked states separately.
