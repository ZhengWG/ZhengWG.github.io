Concept

The Composite pattern composes objects into a tree structure to represent a “whole-part” hierarchy, and lets users treat individual objects and composite objects uniformly. The key points of the design are:

  • Clarify the relationship between parts and the whole, and understand how the objects are composed
  • The Composite pattern is a tree structure with a hierarchy. A leaf node that cannot be divided further is a concrete component, that is, the smallest logical unit. A node that has child nodes (made up of multiple child components) is called a composite component, that is, a composite object. Users use composite components and child components in a consistent way.

The advantages of the Composite pattern are:

  • It is simple to call: a composite object can be used like an ordinary object
  • A composite object can freely add and remove components, so different objects can be combined flexibly

Its drawback is:

  • If the hierarchy is too deep, the composite structure becomes very complex

Scenarios where the Composite pattern applies:

  • There is a clear “part-whole” relationship, or hierarchy, between objects
  • Composite objects and single objects have the same or similar behavior (methods), and users want to use all the objects in the composite structure uniformly

from abc import ABCMeta, abstractmethod


class Component(metaclass=ABCMeta):
    """子组件"""

    def __init__(self, name):
        self._name = name

    def get_name(self):
        return self._name

    def is_composite(self):
        return False

    @abstractmethod
    def feature(self, indent):
        # indent仅用于内容输出时的缩进
        pass


class Composite(Component):
    """复合组件"""

    def __init__(self, name):
        super().__init__(name)
        self._components = []

    def add_component(self, component):
        self._components.append(component)

    def remove_component(self, component):
        self._components.remove(component)

    def is_composite(self):
        return True

    def feature(self, indent):
        indent += "\t"
        for component in self._components:
            print(indent, end="")
            component.feature(indent)

import os

class FileDetail(Component):
    """文件详情"""
    def __init__(self, name):
        super().__init__(name)
        self._size = 0

    def set_size(self, size):
        self._size = size

    def get_file_size(self):
        return self._size

    def feature(self, indent):
        # 文件大小，单位：KB，精确度：2位小数
        file_size = round(self._size / float(1024), 2)
        print("文件名称: %s，文件大小：%s KB" % (self._name, file_size))


class FolderDetail(Composite):
    """文件夹详情"""
    def __init__(self, name):
        super().__init__(name)
        self._count = 0

    def set_count(self):
        return self._count

    def feature(self, indent):
        print("文件名： %s，文件数量：%d。包含的文件：" % (self._name, self._count))
        super().feature(indent)
