Concept

The Memento pattern captures an object’s internal state without breaking its internal structure, so that the object can later be restored to its previously saved state. The biggest function of the Memento pattern is backup. It has three main roles:

  • Originator: the object that needs to be backed up
  • Memento (written “Mementor” in the source): the backed-up state, i.e. a saved archive
  • Caretaker: the manager of the saved archives, responsible for interacting with the originator

Advantages of the Memento pattern:

  • It can restore a previous state
  • It encapsulates information, so users do not need to care about the details of how state is saved

Common scenarios:

  • Save/snapshot scenarios
  • Undo/redo functionality
  • Rollback operations

from copy import deepcopy


class Memento():
    """备忘录"""
    def set_attributes(self, dict):
        """深度拷贝字典dict中的所有属性"""
        self.__dict__ = deepcopy(dict)

    def get_attributes(self):
        """获取属性字典"""
        return self.__dict__


class Caretaker():
    """备忘录管理类"""
    def __init__(self):
        self._mementors = {}

    def add_memento(self, name, memento):
        # 不同name不同备忘录
        self._mementors[name] = memento

    def get_memento(self, name):
        return self._mementors[name]

class Originator():
    """备份发起人"""
    def create_memento(self):
        memento = Memento()
        memento.set_attributes(self.__dict__)
        return memento

    def restore_from_memento(self, memento):
        self.__dict__.update(memento.get_attributes())

class TerminalCaretaker(Caretaker):
    """终端命令的备忘录管理类"""
    def show_history_cmds(self):
        """显示历史命令"""
        for key, obj in self._mementors.items():
            name = ""
            value = []
            if obj._TerminalCmd.__cmd_name:
                name = obj._TerminalCmd.__cmd_name
            if obj._TerminalCmd.__cmd_args:
                value = obj._TerminalCmd.__cmd_args
            print("第%s条命令：%s %s" % (key, name, value))
