Problem Definition of Object Tracking

Object tracking is divided into dense tracking (a series of detections) and sparse tracking (estimation + common sense). The former essentially runs detection on every frame, which requires more computation and is poor in real-time performance. So the object tracking problem generally refers to sparse tracking: estimate the position of the detected target, then process the pixel region near the estimated position to obtain the precise position of the region to be tracked, which gives much better real-time performance.

A Brief Overview of Object Tracking Algorithms

By how they model the problem, traditional object tracking algorithms fall into two classes: generative models and discriminative models. (The former model the joint distribution of inputs and outputs; the latter fit the input-output relationship directly. The latter are less interpretable but generally work better.)

Generative Models

Common generative models:

  • LK optical flow: assumes that the gray level of the target stays unchanged over a short time, and that the velocity vector field in the target’s neighborhood changes slowly
  • KLT: tracks the target by matching corner points (or colors, shapes, or more complex features)
  • L1 tracker: treats tracking as a sparse approximation problem and tracks the target by solving an L1-norm minimization.
  • Local features such as SIFT/SURF/MESR describe the object and are used to track it
  • Filters of various kinds, such as Kalman filter / particle filter / meanshift: predict the position from observations and the state transition equation

Discriminative Models

  • Linear discriminant analysis: uses linear discriminant analysis to adaptively select the color features that best separate the current background from the target, which isolates the target; various classifiers are then introduced on top of this
  • Machine learning methods such as support vector machines and AdaBoost are used to separate background from target.
  • Harr+Boosting
  • TLD: detects the target with online Ferns and tracks it with an online random forest algorithm
  • Struck: uses a structured support vector machine (SVM) to output the tracked target directly
  • Regression-based discriminative models:

The idea of regression models: sample around the original target position p, train a regressor (using HOG or other local features) that can compute the response of a small sampled window. The regressor from the current frame computes the responses of the samples around p in the next frame, and the sample with the strongest response is taken as the position in this frame.

  • KCF: see KCF analysis for details. The distinguishing feature of KCF is that it replaces sampling with cyclic shifts of the samples (implemented by multiplying with permutation matrices), in order to speed things up. Its algorithmic tricks include: ridge regression in kernel space turns the nonlinear classification problem into a linear one, and applying the Fourier transform to circulant matrices reduces the time complexity of the original transformation from o4->o3.

Deep Learning Methods

See A Survey of Video Object Detection Based on Deep Learning for details.

  • T-CNN: builds a detection and tracking framework on tubelets over the time sequence, divided into a tubelet extraction module and a tubelet classification and re-scoring module
  • Flow-Guided Feature Aggregation: extracts optical flow with FlowNet, fuses the flow features of adjacent frames, and finally performs aggregation to obtain the detection result
  • Association LSTM: stacks the features of adjacent frames and passes them through an LSTM (two layers) to regress detection boxes under temporal features
  • Aligned Spatial-Temporal Memory: compared with LSTM, its advantage is that it is a bidirectional recurrent convolutional network, so it can use more frames before and after the current one.
  • MANet: extracts deep features and the optical flow features of adjacent frames at the same time, and calibrates deep features against flow features (at both pixel level and instance level)
