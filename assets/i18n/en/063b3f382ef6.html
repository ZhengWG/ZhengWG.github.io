Basic Key Bindings

Only the key bindings I use frequently are recorded here:

Cursor movement:

  • C-f,C-b,C-n,C-p move forward, backward, up, and down respectively
  • C-a,C-e move to the beginning and the end of the line
  • S-a,S-e move up and down by every other line
  • S->,S-< move to the beginning and the end of the file
  • S-g g moves to a specified line
  • C-l cycles the position of the cursor’s line in the window: center, top, bottom, original position

Buffer switching:

  • C-x C-b opens a window listing all buffers
  • C-x b switches to the specified buffer
  • C-x k kills the specified buffer

Windows:

  • C-x 0 closes the current window
  • C-x 1 shows only the current window
  • C-x 2 splits the current window horizontally
  • C-x 3 splits the current window vertically
  • C-x 4 f opens the specified file in the vertically opened window
  • C-x 4 d opens the specified directory in the vertically opened window (dired-mode)
  • C-x o moves the cursor between windows

Region editing:

  • C-S-Space starts selection mode; move the cursor to select
  • C-k deletes the rest of the line after the cursor
  • C-/ undoes the last operation
  • C-w deletes the region
  • M-w copies
  • C-y pastes

Files:

  • C-x C-f finds a file in the current directory
  • C-x C-s saves the current file
  • C-x s saves the files in the buffers one by one

Other functions:

  • C-h,v,f look up help information for key bindings, variables, and functions
  • C-g cancels a command
  • M-x xxx opens the xxx mode or runs the function, etc.
  • C-x C-e evaluates a piece of Lisp code

Lisp: For the lisp language, see the official quick guide

    (setq ring-bell-function 'ignore)

Features

Loading Features and Installing Packages

Emacs ships with many features, such as recentf: used to open recently opened files. In addition, many more features can be installed through other plugins.

The require command is commonly used to load a feature; require loads a feature from a file:

1
2
3
4
5
6
7
8
9

    (require 'recentf)
    ;; 打开该mode
    (recentf-mode 1)
    ;; 设置最大的文件数目
    (setq recentf-max-menu-item 10)
    ;; 设置快捷键
    (global-set-key (kbd "C-x C-r") 'recentf-open-files)
    ;; 默认文本解码设置为UTF-8
    (set-language-environment "UTF-8")

For different modules, you can use a modular design by type: for example, add modules of different types to the lisp directory under the config folder, but the location must be added in the initialization file init.el: (add-to-list 'load-path "~/.emacs.d/lisp/") . At the same time, add (provide 'modul-name) in the module file, and then the init.el file can load it with the =require= command.

Some modes are triggered only under certain conditions when they are enabled. This is where hooks are used, for example:

1

    (add-hook 'emacs-lisp-mode-hook 'show-paren-mode)

This command means that show-paren-mode is started only when emacs-lisp-mode is started, and it is used to highlight matching parentheses.

The default package sources are very limited (you can check them with M-x package-list-packages), so you can use an external package source to get updates. A commonly used one is MELPA , which contains about 3000 plugins. It can be set up with the following commands:

1
2
3
4

    (require 'package)
         (package-initialize)
         (setq package-archives '(("gnu"   . "http://elpa.emacs-china.org/gnu/")
                          ("melpa" . "http://elpa.emacs-china.org/melpa/"))))

In the resulting packages list, press I to mark a package for installation, D to mark it for deletion, and U to mark it for update. After marking, press X to confirm.

    (require 'cl)

    ;; Add Packages
    (defvar my/packages '(
                   ;; --- Auto-completion ---
                   company
                   ;; --- Better Editor ---
                   hungry-delete
                   swiper
                   counsel
                   smartparens
                   ;; --- Major Mode ---
                   js2-mode
                   ;; --- Minor Mode ---

                   ;; --- Themes ---
                   monokai-theme
                   ;; solarized-theme
                   ) "Default packages")

    (setq package-selected-packages my/packages)

    (defun my/packages-installed-p ()
        (loop for pkg in my/packages
              when (not (package-installed-p pkg)) do (return nil)
              finally (return t)))

    (unless (my/packages-installed-p)
        (message "%s" "Refreshing package database...")
        (package-refresh-contents)
        (dolist (pkg my/packages)
          (when (not (package-installed-p pkg))
            (package-install pkg))))

Overview of Basic Features

Here is a brief introduction to some features that Emacs ships with:

Major Mode: the mode type that corresponds to the file as a whole, such as text-mode, special-mode, and prog-mode

Minor Mode: a mode that provides additional functionality

You can define different Major Modes to be enabled for different files:

1
2
3
4
5

    (setq auto-mode-alist
          (append
           '(("\\.js\\'" . js2-mode))
           '(("\\.html\\'" . web-mode))
           auto-mode-alist))

Some of the built-in features:

  • recentf : recently opened files. After changing the key binding, C-c C-r opens the recent files
  • cl : Common Lisp Extension
  • Org-mode: see the Org-mode introduction on my blog
    • Capture : lets you define templates for adding entries; see the blog post for details
    • Agenda : a schedule management tool
    • Pomodoro : the Pomodoro technique

Commonly Used Plugins

After installing a plugin, you can use M-x customize-group and select the plugin’s name to configure its features.

  • company : provides various auto-completion features. To apply it globally: =(global-company-mode t)= . company completes through company-backends; to complete Python, for example, you need to activate anaconda-mode in the mode hook,

The current value of backends can be obtained with C-h v company-backends

  • hungry-delete : deletes multiple spaces or newlines at once
  • swiper : this plugin actually integrates three plugins, swiper , counsel , and Ivy. Ivy is used for completion (file lookup and matching, etc.), swiper finds the position of a string in the current file, and counsel provides more functions and matches them with Emacs commands so that Ivy can be used better,

C-s performs the search, and the same command switches between search results

  • smartparens : highlights the matching parentheses
  • popwin-mode : moves the cursor into the newly opened window
  • Hippie : provides more completion features, such as completing strings from other buffers
  • Dired : provides powerful file management features. C-x d enters Dired-mode, where you can operate on files, and C-x C-q makes the buffer editable (for example, to rename files). Other convenient operations are:
    • + : create a directory
    • C : copy
    • D : delete
    • d : mark for deletion
    • u : remove the mark
    • x : execute the marks
  • expand-region : selects content with C-=. This key binding needs to be bound: 
    1

        (global-set-key (kbd "C-=") 'er/expand-region)
  • Occur-mode : searches for a string and displays the lines containing it; you can edit in the displayed buffer. M-s o searches for and displays the selected content, and pressing =e enters edit mode
  • iedit-mode : edits all occurrences of the selected content together. After selecting content, M-s e enters iedit mode (the key binding needs to be bound): 
    1

        (global-set-key (kbd "M-s e") 'iedit-mode)
  • Evil : implements most of the functionality of Vim
  • Cask : Cask helps manage Packages. After installation it generates a Cask file under the .emacs.d directory that integrates the Packages, and cask install installs the packages automatically. After that, use it together with pallet to install and manage packages. The following needs to be set in the initialization file: 
    1
2

        require 'cask "<path-to-cask>/cask.el")
    (cask-initialize)    ; 类似于 package-initialize
  • pallet : a package management tool based on Cask that can manage packages across different Emacs versions, among other things. The configuration process is as follows:

    (pallet-mode)
    (pallet-init)    ; 在.emacs.d 中生成一个 Cask 文件, 写入源与现有包
    (pallet-install) ; 将 elpa 中的 package 拷贝到.Cask/<you version>/elpa 目录中

    ;; 配置过程
    (require 'pallet)
    (pallet-mode t)      ; 激活 pallet, 在安装包时将 Cask 文件写入相应信息
  • use-package : a safer way to load packages. When some package fails, it does not stop the whole Emacs from working. It lets you configure each package in one place, making auto-load and key bindings easy. Simple usage is as follows:

  • JavaScript:
    • js2-mode : js2-mode mainly provides syntax highlighting and a syntax checker (Linter)
    • nodejs-repl : can be used to execute the code in a buffer; NodeJS must already be installed on the system
    • js2-refactor : a Minor Mode for refactoring JavaScript; C-c C-m adds the function prefix
  • web-mode : a commonly used Major Mode for editing front-end code
