Concept

The Strategy pattern encapsulates each algorithm and makes them interchangeable, so that the algorithm can vary independently of the users that use it. The three roles in this pattern are:

  • Context: acts as a link between the layers; it shields upper-level applications from direct access to the strategy (algorithm) and encapsulates possible changes
  • Strategy (abstraction): the abstract class of strategies (algorithms); it defines a unified interface and specifies the methods each subtype must implement
  • Concrete strategies: the concrete implementers of the strategy; there can be several different algorithms and rule implementations

Advantages of the Strategy pattern:

  • Algorithms/rules can be switched freely
  • It avoids multiple conditional checks
  • It makes it convenient to extend and add new algorithms (rules)

Disadvantages:

  • All strategy classes need to be exposed to the outside

Applicable scenarios:

  • When a system has many classes that differ only in their behavior/strategy, the Strategy pattern lets an object dynamically choose among many behaviors
  • When designing a program interface, if you want some of the internal implementation to be supplied by the caller

from abc import ABCMeta, abstractmethod


class Person():
    """人类"""
    def __init__(self, name, age, weight, height):
        self.name = name
        self.age = age
        self.weight = weight
        self.height = height

    def show_myself(self):
        print("%s 年龄：%d 岁，体重：%0.2f kg，身高: %0.2f m" % (self.name, self.age, self.weight, self.height))


class ICompare(metaclass=ABCMeta):
    """比较算法"""
    @abstractmethod
    def comparable(self, person1, person2):
        "person1 > person2 返回值>0, person1 == person2 返回0，person1 < person2 返回值小于0"
        pass


class CompareByAge(Icompare):
    """通过年龄排序"""
    def comparable(self, person1, person2):
        return person1.age - person2.age


class CompareByHeight(IComparable):
    """通过身高排序"""
    def comparable(self, person1, person2):
        return person1.height - person2.height


class SortPerson():
    """Person的排序类"""
    def __init__(self, compare):
        self.__compare = compare

    def sort(self, person_list):
        """排序算法
        这里采用最采用的冒泡排序"""
        n = len(person_list)
        for i in range(0, n-1):
            for j in range(0, n-i-1):
                if self.__compare.comparable(person_list[j], person_list[j+1]) > 0:
                    tmp = person_list[j]
                    person_list[j] = person_list[j + 1]
                    person_list[j + 1] = tmp
