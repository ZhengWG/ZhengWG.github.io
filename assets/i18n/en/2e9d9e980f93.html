Concept

The Decorator pattern dynamically adds some extra responsibilities to an object. For extending an object, the Decorator pattern is more flexible than generating subclasses. Functionally it is similar to Python’s built-in decorators, but the Decorator pattern approaches the problem from the design-pattern angle and usually decorates a specified method of a class (Python decorators are used in many more and more varied ways). The key points of the design are:

  • Responsibilities can be added to an object, and its functionality extended, flexibly
  • Any number of decorations can be added
  • Different decoration orders may produce different effects

Design Template

The Decorator pattern usually involves designing a decorator. In Python there are generally two kinds: decorating a function and decorating a class. For details, see: Python: Common Decorators.

from abc import ABCMeta, abstractmethod


class Person(metaclass=ABCMeta):
    "人"

    def __init__(self, name):
        self._name = name

    @abstractmethod
    def wear(self):
        print("着装：")


class Engineer(Person):
    "工程师"

    def __init__(self, name, skill):
        super().__init__(name)
        self.__skill = skill

    def getSkill(self):
        return self.__skill

    def wear(self):
         print("我是 " + self.getSkill() + "工程师 " + self._name, end=", ")
         super().wear()


class Teacher(Person):
    "教师"

    def __init__(self, name, title):
        super().__init__(name)
        self.__title = title

    def getTitle(self):
        return self.__title

    def wear(self):
         print("我是 " + self._name + self.getTitle(), end=", ")
         super().wear()


class ClothingDecorator(Person):
    "服装装饰器的基类"

    def __init__(self, person):
        self._decorated = person

    def wear(self):
        self._decorated.wear()
        self.decorate()

    @abstractmethod
    def decorate(self):
        pass


class CasualPantDecorator(ClothingDecorator):
    "休闲裤装饰器"

    def __init__(self, person):
        super().__init__(person)

    def decorate(self):
        print("一条卡其色休闲裤")


def BeltDecorator(ClothingDecorator):
    "腰带装饰器"

    def __init__(self, person):
        super().__init__(person)

    def decorate(self):
        print("一条银色针扣头的黑色腰带")
