Preface

Python’s built-in libraries include quite a few commonly used data structures, and using them well can greatly improve the efficiency of solving problems and implementing solutions. Two commonly used data structures are introduced below:

  • Priority queue
  • Max (min) binary heap

Data Structure Overview

Priority Queue

  • Brief introduction

    In a priority queue, each element in the queue has its own priority. Getting the element with the highest priority takes O(1) time.

  • Use cases

    It is commonly used for problems that ask for the maximum or minimum within a range. A priority queue usually yields an O(n) solution, which takes some technique

  • Simple implementation

    It can be implemented simply with the collections.deque double-ended queue. The advantage of a double-ended queue over a list is that it is implemented as a doubly linked list, so insertion and deletion at both the left and right ends take O(1) time.

    from collections import deque
    
nums = deque(sorted([1, 45, 2, 4, 61, 5]))  # 随机输入的数组,得到排序后的结果
print(nums)  # deque([1, 2, 4, 5, 45, 61])
    
# 后侧新插入元素，需要继续保持优先队列特性，且对前面的元素进行压缩
inserted_num = 20
while (inserted_num < nums[-1]):
    nums.pop()
nums.append(inserted_num)
print(nums)  # deque([1, 2, 4, 5, 20])
    
# 前侧新插入元素，需要继续保持优先队列特性，且对后面的元素进行压缩
inserted_num = 3
while (inserted_num > nums[-1]):
    nums.popleft()
nums.appendleft(inserted_num)
print(nums)  # deque([3, 4, 5, 20])

Max (Min) Binary Heap

  • Brief introduction

    The max (min) binary heap is a commonly used data structure, built as a complete binary tree. Building the heap takes O(nlogn) time, and inserting or deleting elements, followed by the adjustment, takes log(n) time. Heap sort is a fairly stable sort.

  • Use cases

    The advantage of the max (min) binary heap is that the maximum/minimum element can be obtained quickly, in O(1) time. It can solve most topk problems and problems that require maintaining a data structure dynamically.

  • Simple implementation

    The heapq module implements a min binary heap. Its basic operations are briefly introduced below:

inserted_num = 0
heapq.heappush(l, inserted_num)
print(l)  # [0, 5, 4, 23, 54, 45]

from collections import deque
import heapq


class Solution:
    @staticmethod
    def getmaxvalue(nums):
        max_value = float('-inf')
        for num in nums:
            if num > max_value:
                max_value = num
        return max_value

    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        # 最基础：O(nk)
        # 进阶：O(nlog(k))，最大堆
        # 最终：O(n)，单调栈

        if len(nums) <= k:
            return [Solution.getmaxvalue(nums)] 

        # 基础版本,通过率：49/61
        window = deque()
        res = []
        for num in nums:
            window.append(num)
            if len(window) >= k:
                res.append(Solution.getmaxvalue(window))
                window.popleft()

        # 进阶版本, 最大堆，all pass
        windows = [(-nums[idx], idx) for idx in range(k)]
        heapq.heapify(windows)
        res = [-windows[0][0]]
        for idx, num in enumerate(nums[k:]):
            heapq.heappush(windows, (-num, idx + k))
            while (windows[0][1] <= idx):
                heapq.heappop(windows)
            res.append(-windows[0][0])

        # 最终版本，单调队列（递增）
        windows = deque()
        for idx in range(k):
            while windows and nums[windows[-1]] <= nums[idx]:
                windows.pop()
            windows.append(idx)
        res = [nums[windows[0]]]

        for idx, num in enumerate(nums[k:]):
            while windows and nums[windows[-1]] <= num:
                windows.pop()
            windows.append(idx + k)
            while(windows[0] <= idx):
                windows.popleft()
            res.append(nums[windows[0]])

        return res
