Frustum ConvNet: Sliding Frustums to Aggregate Local Point-Wise Features for Amodal 3D Object Detection

Background and Core Idea

Motivation: this paper builds on the idea of Frustum PointNets. It argues that Frustum PointNets is not end to end, and that its final 3D box prediction depends heavily on the 3D point cloud segmentation result, so missing points in the earlier module make the later prediction inaccurate.

Algorithm Pipeline

  • Core points:
    • The frustum obtained from the 2D detection result is divided equally into T sections. PointNet features are extracted for every frustum section to form a 2D feature map (L*d), and an FCN (kernel: 3*d) performs box classification and position prediction for each section
    • Frustum splitting uses several groups of strides, and features are fused at multiple scales at different stages of the network

Algorithm Details

Other details:

  • Focal loss is used to balance foreground and background

  • Final refinement: after the 3D box output is obtained, the predicted 3D box is expanded and normalized (the box is enlarged by a factor (1.2) with its orientation unchanged), and the points inside these boxes are fed into the network again for a second round of refinement.
