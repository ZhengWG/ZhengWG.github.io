# Calculating Eigenvectors and eigenvalues of Cov matrix
mean_vec = np.mean(X_std, axis=0)
cov_mat = np.cov(X_std.T)
eig_vals, eig_vecs = np.linalg.eig(cov_mat)
# Create a list of (eigenvalue, eigenvector) tuples
eig_pairs = [(np.abs(eig_vals[i]), eig_vecs[:,i])
             for i in range(len(eig_vals))]

# Sort the eigenvalue, eigenvector pair from high to low
eig_pairs.sort(key=lambda x: x[0], reverse=True)
# Calculation of Explained Variance(可解释方差) from the eigenvalues
tot = sum(eig_vals)
# Individual explanined variance(个体可解释方差)
var_exp = [(i/tot)*100 for i in sorted(eig_vals, reverse=True)]
# (累积可解释方差)
cum_var_exp = np.cumsum(var_exp)

The figure shows that t-SNE separates the classes well, better than the earlier PCA and LDA, which is due to the algorithm’s topology-preserving property. The drawback of t-SNE is that there may be multiple local minima: in the figure, sub-clusters of the same color are separated into two different regions.

4. Summary

This post briefly summarizes several common dimensionality reduction methods, including PCA (+KMeans), LDA, and t-SNE. There are other dimensionality reduction approaches as well, including Sammon mapping, multidimensional scaling, and some graph-based visualization methods.
