Concept

The Bridge pattern is similar to the Strategy pattern, except that Bridge focuses on software structure while Strategy focuses on object behavior. Its function is to decouple an abstraction from its implementation so that they can vary independently. The class diagram of the Bridge pattern is as follows:

The main use cases are:

  • A product can be divided into multiple categories and combinations, i.e. multiple independently varying dimensions, and each dimension should be extensible independently
  • For systems whose number of classes grows sharply because of inheritance/multiple inheritance, the Bridge pattern can be used instead

Example

Scenario: design a geometry classification. Shapes include rectangle and ellipse, and colors include red and green. With ordinary inheritance, such as shape -> rectangle -> red rectangle, the class diagram becomes bloated as more colors/shapes are added. With the Bridge pattern, the code is as follows:

from abc import ABCMeta, abstractmethod


class Shape(metaclass=ABCMeta):
    """形状"""
    def __init__(self, color):
        self._color = color

    @abstractmethod
    def get_shape_type(self):
        pass

    def get_shape_info(self):
        return self._color.get_color() + "的" + self.get_shape_type()


class Rectange(Shape):
    """矩形"""
    def __init__(self, color):
        super().__init__(color)

    def get_shape_type(self):
        return "矩形"


class Ellipse(Shape):
    """椭圆"""
    def __init__(self, color):
        super().__init__(color)

    def get_shape_type(self):
        return "椭圆"


def Color(metaclass=ABCMeta):
    """颜色"""
    @abstractmethod
    def get_color(self):
        pass


def Red(Color):
    """红色"""
    @abstractmethod
    def get_color(self):
        return "红色"


def Green(Color):
    """绿色"""
    @abstractmethod
    def get_color(self):
        return "绿色"

def test_shape():
    red_rect = Rectange(Red())
    print(red_rect.get_shape_info())
    green_rect = Rectange(Green())
    print(green_rect.get_shape_info())
    red_ellipse = Ellipse(Red())
    print(red_ellipse.get_shape_info())
    green_ellipse = Ellipse(Green())
    print(green_ellipse.get_shape_info())
    """
    测试结果：
    红色矩形
    绿色矩形
    红色椭圆
    绿色椭圆
    """
