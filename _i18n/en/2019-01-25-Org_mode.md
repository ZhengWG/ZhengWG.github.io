# Preface

Org mode is a superb tool in Emacs. Compared with a lightweight format like markdown,
it has more features and is more extensible, but it is not trivial to get started with.
This post only gives a brief introduction to some of its basic features.

On the Ubuntu system used for this post, the Emacs version is 25.1.1 and the Org mode version is 9.2

# Headings and Numbering

Org mode uses \* to mark section headings, and the number of \* gives the heading level:

    * Level 1 heading
    ** Level 2 heading
    *** Level 3 heading

Use `M-[RET]` to insert a heading at the same level, and `M-left/right` to promote or demote a heading.
Use `M-up/down` to move a section (including its subsections) up or down.
Use the `Tab` key to expand or collapse a section, and `S+Tab` to expand or collapse all sections.

Lists come in two kinds, unordered and ordered:

Unordered list:
-   Unordered list 1
-   Unordered list 2
    -   Unordered sublist 3

Ordered list:
1.  Ordered list 1
2.  Ordered list 2
    1.  Ordered sublist 3

Unordered lists use `+ or -` as the prefix, and ordered lists use `1. or 1)` as the prefix:

    Unordered list:
    + Unordered list 1
    + Unordered list 2
      + Unordered sublist 3
    Ordered list:
    1) Ordered list 1
    2) Ordered list 2
       1) Ordered sublist 3

Use =M-[RET]= to enter a new item at the same level, `M-left/right` to promote or demote,
and `M-up/down` to move items up or down.
Use `S-left/right` to switch the list style (for example, from an unordered list to an ordered list).

Another feature of Org lists is that they can contain a **checkbox**.
Its form is [], and placed before a task it marks whether the task is done,
while placed after a task it marks the completion progress. In that case it needs a `%` or `/` inside, such as `[20%]`. The result looks like this:

1.  [-] Total task 1 <code>[33%]</code>
    1.  [ ] Subtask 1
    2.  [X] Subtask 2
    3.  [ ] Subtask 3

A list with **checkbox** items can be created with `M-S-[RET]`.
Use `C-c C-c` to toggle the completion state of a task, and the progress of the total task is counted automatically.

# Tables

Tables in Org mode are written in the following format:

    | name     |   phone | job     | score1 | score2 | total |
    |----------|---------|---------|--------|--------|-------|
    | Zhangsan | 1234455 | student |     19 |     30 |    49 |
    | Lisi     |  423423 | layer   |     20 |     10 |    30 |
    #+TBLFM: $6=$4+$5

You need to set the number of columns in the first row yourself. The `Tab` key completes and moves to the next cell (or the next row).
`|-` expands to `|----------|---------|---------|`. The rendered result is:

# Links

A link looks like this: [My-blog](https://johneyzheng.top). After you enter it, the display changes, and you can edit it with `C-c C-l`

    [[link address][link text]]
    [[https://johneyzheng.top][My_blog]]

Displaying an image is similar:
```
# Image path with file prefix
[[file:/home/path_of_pics]]
# Or a path relative to the current directory
[[./pics/file.jpg]]
```

# Footnotes

A footnote looks like this:

    Text that needs a footnote[fn:2]

Insert one with `C-c C-x f`, and jump to the footnote with `C-c C-c`.
The content is `[fn:num]`, which you can also type in manually.

# Tags

Tags are not used much. You can add a tag to a heading with `C-c C-q`

# TODO Items

TODO is a distinctive feature of Org mode and works as a time management tool (GDK). It looks like this:

## TODO

## TODO

## TODO

### TODO <code>[1/3]</code>

-   [ ] Eat
-   [X] Sleep
-   [ ] Play Doudou

The input is as follows:

    ** TODO [#A]
    ** TODO [#B]
    ** TODO [#C]
    *** TODO [1/3]
    + [ ] sub1
    + [X] sub2
    + [ ] sub3

`S-left/right` switches between the `TODO` and `DONE` states,
`S-up/down` changes the priority, and `M-S-[RET]` inserts a TODO item at the same level.

# Inserting Time

`C-c .` inserts a time. A calendar appears at the bottom, from which you can pick a date, for example:

    * TODO Watch a movie
    SCHEDULED:  <2019-01-25 Fri>
    DEADLINE: <2019-01-27 Sun>

# Font Settings

Common font settings:

    *bold*
    /italic/
    _underlined_
    =code=
    ~verbatim~
    +striken-through+

The result is:

**bold**

*italic*

<span class="underline">underlined</span>

`code`

`verbatim`

<del>striken-through</del>

# Multiple Text Block Formats

Text block formats must be run in different modes. They are usually obtained by completing `<` + a character + `Tab`.
For example, `<s+Tab` gives a source block (after `<s` you need `C-x C-s` to save the buffer). Common usages:

    Set the title and table of contents:
    # +TITLE: This is the title of the document
    # +OPTIONS: toc:2 (only to two levels in TOC)
    # +OPTIONS: toc:nil (no TOC at all)

    Add a quotation:
    # +BEGIN_QUOTE
    Everything should be made as simple as possible,
    but not any simpler -- Albert Einstein
    # +END_QUOTE

    Center text:
    # +BEGIN_CENTER
        Everything should be made as simple as possible,but not any simpler
    # +END_CENTER

    Set an example (the content inside is output directly and is not escaped):
    # +BEGIN_EXAMPLE
    The characters in here are not escaped
    # +END_EXAMPLE
    Comments, which are not exported
    Comment usage#  this is comment
    # +BEGIN_COMMENT
    The comments in here are not exported
    # +END_COMMENT

The characters for the different text block forms are defined as follows:

    s       #+BEGIN_SRC ... #+END_SRC

    e       #+BEGIN_EXAMPLE ... #+END_EXAMPLE

    q       #+BEGIN_QUOTE ... #+END_QUOTE

    v       #+BEGIN_VERSE ... #+END_VERSE

    c       #+BEGIN_CENTER ... #+END_CENTER

    C       #+BEGIN_COMMENT ... #+END_COMMENT

    l       #+BEGIN_EXPORT latex ... #+END_EXPORT

    L       #+LATEX:

    h       #+BEGIN_EXPORT html ... #+END_EXPORT

    H       #+HTML:

    a       #+BEGIN_EXPORT ascii ... #+END_EXPORT

    A       #+ASCII:

    i       #+INDEX: line

    I       #+INCLUDE: line

# Inserting and Running Source Code

The source code format is:

    #+BEGIN_SRC language
    #+END_SRC

The supported languages include `emacs-lisp` , `python`, `sh`, `haskell`, `js`, `latex`, `gnuplot`
, `C`, `sql`, `ditaa`
For example, to insert Python code:

    #+BEGIN_SRC python
      def func:
          b = 1
          a = b + 1
          return a
    #+END_SRC

Use `C-c+'` to edit the code. The displayed result is:

    def func:
        b = 1
        a = b + 1
        return a

You can also run code from the code buffer with the command `C-c C-c`.
To do so, add the following setting to the `.emacs/init.el` file:

    (org-babel-do-load-languages
     'org-babel-load-languages
     '((R . t)
       (emacs-lisp . t)
       (python . t)
       (sh . t)
       (haskell . t)
       (js . t)
       (latex . t)
       (gnuplot . t)
       (C . t)
       (sql . t)
       (ditaa . t)
       ))

To make syntax highlighting and indentation in the code block more convenient, you can add these settings:

    (setq org-src-tab-acts-natively t)
    (setq org-src-fontify-natively t)

The result of running code is:

    #+BEGIN_SRC emacs-lisp
      (+ 1 2 3 4)
    #+END_SRC

    #+RESULTS:
    : 10

Python works the same way:

    #+BEGIN_SRC python :results output
      a = 1+1
      print a
    #+END_SRC

    #+RESULTS:
    : 2

C language:

    #+BEGIN_SRC C :include <stdio.h>
    int a=1;
    int b=2;
    printf("%d", a+b);
    #+END_SRC

    #+RESULTS:
    : 3

# Exporting to Other Formats

An .org file can be exported to many kinds of files, using `C-c C-e`.
By default there is no export setting for `markdown` files,
so add the following to your configuration file:

    ;; export to markdown mode
    (eval-after-load "org"
      '(require 'ox-md nil t))

In addition, exporting Chinese pdf requires some setup. First install texlive and auctex:

    sudo apt-get install texlive texlive-xetex texlive-latex-extra
    sudo apt-get install latex-cjk-all
    sudo apt install auctex

Then add the following settings to the `init.el` file (depending on the Org mode version):

    ;; org-mode < 8.0
    (setq org-latex-to-pdf-process '("xelatex -interaction nonstopmode %f"
                                     "xelatex -interaction nonstopmode %f"))
    ;;  org-mode 8.0
    (setq org-latex-pdf-process '("xelatex -interaction nonstopmode %f"
                                  "xelatex -interaction nonstopmode %f"))

Copy the fonts from Windows: copy `windows/fonts/` to `~/.fonts/`. The files include:

    Files:
    *.TTC
    SIM*.ttf

The header of the file to be exported needs the font settings:

    #+LATEX_HEADER: \usepackage{xltxtra}
    #+LATEX_HEADER: \setmainfont{WenQuanYi Micro Hei}
    Or:
    #+LATEX_HEADER: \usepackage{xeCJK}
    #+LATEX_HEADER: \setCJKmainfont{SimSun}

Finally, run `C-c C-e l p` to output the pdf.

To suppress the table of contents in the output, set the `toc` option at the top of the file. `num` sets the heading level included in the table of contents:

    #+OPTIONS: toc:nil
