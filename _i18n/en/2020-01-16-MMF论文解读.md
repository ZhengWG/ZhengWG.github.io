# Background and Core Idea

Motivation: this paper improves on the authors' earlier work, ContFuse. Although ContFuse fuses image and BEV information, its effect is limited for very sparse point clouds. In addition, the detector head of ContFuse is too simple,


<a id="org64f782d"></a>

# Algorithm Pipeline

-   Core:
    -   A detector head based on ROI-wise fusion is designed, following AVOD
    -   An auxiliary ground plane network is added: a Unet structure predicts the ground height of every voxel in the point cloud voxel space as the ground plane information (BEV). The corresponding height is subtracted from the BEV point cloud information, and the final prediction has the height added back accordingly
    -   A depth completion branch is added to complete the depth and generate a pseudo lidar, which supplements the data where real point cloud information is missing

# Algorithm Details

-   Key points:
    -   The authors argue that extracting proposals from the 2D image is not optimal, and that extracting proposals directly from the BEV map is simpler (consistent sizes and less occlusion)
    -   An online mapping branch
    -   Pseudo lidar can supplement the missing long-range lidar data, and simply adding the depth completion branch for multi-task training also helps
