# ONNX Model Optimization and Quantization Details

## ONNX Basics

+ What is ONNX?

  [ONNX](https://github.com/onnx/onnx) stands for Open Neural Network Exchange, a framework-independent model representation. The ONNX specification and code are developed mainly by Microsoft, Amazon, Facebook, IBM, and other companies, and are hosted on GitHub as open source. The deep learning frameworks that officially support loading ONNX models and running inference are currently Caffe2, PyTorch, MXNet, ML.NET, TensorRT, and Microsoft CNTK, and TensorFlow also supports ONNX unofficially.

+ What does the ONNX data format look like?

  ONNX is essentially a file format that stores the neural network structure and weights in Protobuf data structures. Its organization is defined mainly in [onnx.proto](https://github.com/onnx/onnx/blob/master/onnx/onnx.proto), which defines data structures at the Model/Graph/Node/ValueInfo/Tensor/Attribute level. The whole graph builds the model's topology through the input/output references between nodes (Node).

+ What does ONNX support?

  Based on ONNX models, the official project provides a series of tools: model conversion, model optimization ([simplifier](https://github.com/daquexian/onnx-simplifier) and others), model deployment ([Runtime](https://github.com/microsoft/onnxruntime)), model visualization ([Netron](https://github.com/onnx/onnx/blob/master/onnx/onnx.proto) and others), and so on.

ONNX comes with a Runtime library that can deploy an ONNX Model to different hardware devices for inference, with support for various backends (such as TensorRT/OpenVINO).

The system architecture of the Runtime for an ONNX Model is shown below. The Runtime converts the ONNX Model into an In-Memory Graph format, then turns it into a number of executable subgraphs, and finally assigns the subgraphs to different backends (execution providers) through the GetCapability() API.

## ONNX Model Optimization

The core function of [onnx_simplifier](https://github.com/daquexian/onnx-simplifier) is as follows:

> ONNX Simplifier is presented to simplify the ONNX model. It infers the whole computation graph and then replaces the redundant operators with their constant outputs.

The basic simplify procedure is:

1. Use onnxruntime to run inference on the computation graph and obtain the inferred input and output shapes of every node
2. Optimize the ONNX model with the optimization methods that ONNX supports (such as `fuse_bn_into_conv`)
3. Fold the constant OPs of the ONNX model:
   1. Obtain the constant OPs with `get_constant_nodes`
   2. Use `add_features_to_output` to extend the outputs of all static nodes into the output node list of the ONNX graph (mainly so that the outputs of the constant nodes are easy to retrieve in later steps)
   3. Remove the constant OPs obtained in step 1 from the graph (disconnect their edges), and build their node parameters into input parameters of other nodes
   4. Clean up the isolated nodes in the graph (the nodes disconnected in step 3)

Its optimize function is defined as follows (you can take a quick look at the optimization methods currently supported):

```python
def optimize(model: onnx.ModelProto, skip_fuse_bn: bool, skipped_optimizers: Optional[Sequence[str]]) -> onnx.ModelProto:
    """
    :model参数: 待优化的ONXX模型.
    :return: 优化之后的ONNX模型.
    简化之前, 使用这个方法产生会在'forward_all'用到的ValueInfo
    简化之后，使用这个方法去折叠前一步产生的常量到initializer中并且消除没被使用的常量
    """
    onnx.checker.check_model(model)
    onnx.helper.strip_doc_string(model)
    optimizers_list = [
        'eliminate_deadend',
        'eliminate_nop_dropout',
        'eliminate_nop_cast',
        'eliminate_nop_monotone_argmax', 'eliminate_nop_pad',
        'extract_constant_to_initializer', 'eliminate_unused_initializer',
        'eliminate_nop_transpose',
        'eliminate_nop_flatten', 'eliminate_identity',
        'fuse_add_bias_into_conv',
        'fuse_consecutive_concats',
        'fuse_consecutive_log_softmax',
        'fuse_consecutive_reduce_unsqueeze', 'fuse_consecutive_squeezes',
        'fuse_consecutive_transposes', 'fuse_matmul_add_bias_into_gemm',
        'fuse_pad_into_conv', 'fuse_transpose_into_gemm', 'eliminate_duplicate_initializer'
    ]
    if not skip_fuse_bn:
        optimizers_list.append('fuse_bn_into_conv')
    if skipped_optimizers is not None:
        for opt in skipped_optimizers:
            try:
                optimizers_list.remove(opt)
            except ValueError:
                pass

    model = onnxoptimizer.optimize(model, optimizers_list, fixed_point=True)
    onnx.checker.check_model(model)
    return model
```

## Converting ONNX to FP16

ONNX supports converting an FP32 model to an FP16 model. The interface is as follows:

```python
import onnxmltools
from onnxmltools.utils.float16_converter import convert_float_to_float16

# Update the input name and path for your ONNX model
input_onnx_model = 'model.onnx'
# Change this path to the output name and path for your float16 ONNX model
output_onnx_model = 'model_f16.onnx'
# Load your model
onnx_model = onnxmltools.utils.load_model(input_onnx_model)
# Convert tensor float type from your input ONNX model to tensor float16
onnx_model = convert_float_to_float16(onnx_model)
# Save as protobuf
onnxmltools.utils.save_model(onnx_model, output_onnx_model)
```

The implementation is in [float16.py](https://github.com/microsoft/onnxconverter-common/blob/master/onnxconverter_common/float16.py). The truncation logic is:

+ Values below the minimum precision (default 1e-7) are mapped to the minimum precision
+ Values above the maximum range (default 1e4) are mapped to the maximum value
+ NaN/0/inf/-inf keep their original values

Core code:

```python
def convert_np_to_float16(np_array, min_positive_val=1e-7, max_finite_val=1e4):
    def between(a, b, c):
        return np.logical_and(a < b, b < c)
    np_array = np.where(between(0, np_array, min_positive_val), min_positive_val, np_array)
    np_array = np.where(between(-min_positive_val, np_array, 0), -min_positive_val, np_array)
    np_array = np.where(between(max_finite_val, np_array, float('inf')), max_finite_val, np_array)
    np_array = np.where(between(float('-inf'), np_array, -max_finite_val), -max_finite_val, np_array)
    return np.float16(np_array)
```
