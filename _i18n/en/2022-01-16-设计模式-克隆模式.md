# Concept<a id="sec-1"></a>

The core of the Prototype pattern is to create a new object by copying the attributes of an existing one. The key method is the `clone` method, which involves two steps:

-   Allocate a new block of memory for the new object
-   Copy all the attributes of the original object

The characteristics of the Prototype pattern are:

-   It copies by duplicating memory, which performs better than creating an object with new
-   You can choose to design either a shallow copy or a deep copy
-   When an object is created through clone, the class's `__init__` initialization function is not executed

# Design Template<a id="sec-2"></a>

The Prototype pattern is fairly simple. A simple framework is as follows:

```python
from copy import copy, deepcopy


class Clone:
    "基类"

    def clone(self):
        "浅拷贝方式"
        return copy(self)

    def deepclone(self):
        "深拷贝方式"
        return deepcopy(self)
```
