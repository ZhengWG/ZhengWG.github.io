# Preface<a id="sec-0"></a>

**\#finished on 2022/02/02 Finished organizing the design patterns~**

I learned from Mr. Luo Jianfeng's three maxims:

> Anyone can write code that a machine can understand, but only a good programmer can write code that a human can understand.
>
> There are two ways to write a program: one is to make the code so complicated that "there are no obvious errors"; the other is to make the code so simple that "there are obviously no errors".
>
> "Making correct code fast" is much easier than "making fast code correct"

**\#update on 2021/10/06 Started the design patterns series**

This summarizes the basic concept and template of each design pattern. Design patterns originate from the book *Design Patterns: Elements of Reusable Object-Oriented Software* by the **Gang of Four (GoF)**, which describes 23 classic design patterns. This article mainly draws on *Design Patterns for Everyone*, and it likewise summarizes only the basic 23 patterns.
