# Background<a id="sec-1"></a>

C++ is a multi-paradigm programming language that lets developers choose the best design approach for their specific needs. It covers the following five paradigms:

| Programming paradigm | Characteristics                      | Application scenarios               |
| Procedural programming | Based on functions and steps, operates on global variables, simple and direct. | Small programs, script-style tasks   |
| Object-oriented programming | Encapsulates data and behavior, supports inheritance and polymorphism, suits the design of complex systems. | Game development, GUI applications, enterprise systems |
| Generic programming | Type-independent, general-purpose code design that improves code reuse and performance. | Data structures, algorithm libraries (such as the STL) |
| Functional programming | Pure functions and higher-order functions, avoiding state and side effects. | Concurrent programming, big data processing, distributed systems |
| Metaprogramming | Compile-time computation and optimization that reduce runtime overhead and improve performance. | Library design, performance optimization (such as Eigen and Boost) |

# Procedural Programming<a id="sec-2"></a>

Core idea: a program consists of a series of functions and steps, executed in a certain order. Characteristics:

-   It emphasizes functions and procedures.

-   It shares data through global variables and parameter passing.

-   It is easy to implement and understand, but as programs grow larger, the code can become hard to maintain.

```c++
#include <iostream>
#include <string>

// 全局变量
std::string global_str = "Demo: ";

void greet(const std::string& message) {
    std::cout << global_str << message << std::endl;
}

int main() {
    std::string message = "你好";
    greet(message);
    return 0;
}
```

# Object-Oriented Programming<a id="sec-3"></a>

New C++ features strengthen the definition and manipulation of classes, making object-oriented programming more flexible. Characteristics:

-   Explicit virtual function overriding (override, final): prevents erroneous function overriding.

-   Defaulted and deleted functions (=default, =delete): control the generation of special member functions.

-   Inheriting constructors: simplify the construction of subclasses.

```c++
#include <iostream>
#include <string>

class Base {
public:
    virtual void show() const = 0;
    virtual ~Base() = default; // 默认析构函数: 编译器构造
    Base& operator=(const Base&) = delete; // 禁用赋值运算符
};

class Derived final : public Base { // final: Derived类不可继承
public:
    void show() const override { // 显式覆盖
        std::cout << "Derived class" << std::endl;
    }
};

int main() {
    Base* obj = new Derived();
    obj->show(); // 输出: Derived class
    delete obj;
    return 0;
}
```

# Generic Programming<a id="sec-4"></a>

Templates are the core of C++ generic programming, and the new template features introduced since C++11 make template programming more powerful. Characteristics:

-   Variadic templates: support any number of template parameters.

-   Template aliases: simplify the use of templates.

-   Automatic deduction (auto, decltype): strengthen type deduction.

```c++
#include <iostream>

// 特化模板
template <>
void print<std::string value> {
    std::cout << "String: " << value << std::endl;
}

// 递归展开的变参模板
template<typename T>
void print(T value) {
    std::cout << value << std::endl;
}

template<typename T, typename... Args> // 类型参数包，可以匹配任意数量和类型的模板参数
void print(T value, Args... args) {
    std::cout << value << " ";
    std::cout << ... << args << std::endl; // C++17
    print(args...); // C++11: 递归调用
}

int main() {
    print(1, 2.5, "Hello", 'A'); // 输出: 1 2.5 Hello A
    return 0;
}
```

# Functional Programming<a id="sec-5"></a>

C++11 and later support functional programming by introducing features such as `lambda` expressions and `std::function`. Characteristics:

-   Lambda expressions
    
    They allow defining anonymous functions.

```c++
// [捕获列表](参数列表) mutable -> 返回类型 { 函数体 }
// 样例：
//     1. 混合捕获所有变量，除了var按照引用捕获
//     2. mutable表示支持函数内部修改捕获的非引用值，外部不受影响
//     3. double指定函数返回类型
#include <iostream>

int x = 5;
auto divide = [=, &var](int a, int b) mutable -> double {return (double)a / b; };
std::cout << divide(5, 2) << std::endl;

```

-   std::function: provides general-purpose storage for function objects.

-   std::bind: binds function arguments.

```c++
#include <iostream>
#include <functional>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> nums = {1, 2, 3, 4, 5};

    // 使用Lambda表达式
    auto square = [](int x) { return x * x; };
    for (int num : nums) {
        std::cout << square(num) << " ";
    }
    std::cout << std::endl;

    // 使用std::function存储Lambda
    std::function<int(int)> multiply_by_2 = [](int x) { return x * 2; };
    std::cout << multiply_by_2(10) << std::endl;

    // 使用std::bind
    auto add = [](int a, int b) { return a + b; };
    auto add_five = std::bind(add, 5, std::placeholders::_1);
    std::cout << add_five(3) << std::endl;

    return 0;
}
```

# Metaprogramming<a id="sec-6"></a>

Metaprogramming is an advanced C++ feature that is widely used in the implementation of the standard library and modern libraries (such as Boost and Eigen), and it matters for improving performance, flexibility, and type safety. Through new features such as constexpr and type_traits, C++ supports compile-time computation and type manipulation. Characteristics:

-   constexpr: allows computation at compile time.
    
    ```c++
    #include <iostream>
    #include <type_traits>
    
    // constexpr函数
    constexpr int factorial(int n) {
        return (n <= 1) ? 1 : n * factorial(n - 1);
    }
    
    int main() {
        constexpr int result = factorial(5); // 编译时计算
        std::cout << "Factorial of 5 is " << result << std::endl;
    
        // 使用type_traits
        std::cout << std::boolalpha;
        std::cout << "Is int integral? " << std::is_integral<int>::value << std::endl;
        std::cout << "Is float integral? " << std::is_integral<float>::value << std::endl;
    
        return 0;
    }
    ```

-   type_traits: provides type trait checks.
    
    ```c++
    #include <iostream>
    #include <type_traits>
    
    // 检查类型是否为整数：std::is_integral
    int main() {
        std::cout << std::boolalpha;
        std::cout << "Is int an integral type? " << std::is_integral<int>::value << std::endl; // true
        std::cout << "Is float an integral type? " << std::is_integral<float>::value << std::endl; // false
        return 0;
    }
    ```

-   if constexpr: compile-time conditional branches.
    
    ```c++
    #include <iostream>
    #include <type_traits>
    
    // C++11: 仅对整数类型有效
    template <typename T>
    typename std::enable_if<std::is_integral<T>::value, void>::type
    print(T value) {
        std::cout << "Integral: " << value << std::endl;
    }
    
    // C++11: 仅对浮点数类型有效
    template <typename T>
    typename std::enable_if<std::is_floating_point<T>::value, void>::type
    print(T value) {
        std::cout << "Floating Point: " << value << std::endl;
    }
    
    // C++17
    template <typename T>
    void print(T value) {
        if constexpr (std::is_integral<T>::value) {
            std::cout << "Integral: " << value << std::endl;
        } else if constexpr (std::is_floating_point<T>::value) {
            std::cout << "Floating Point: " << value << std::endl;
        } else {
            std::cout << "Unknown type!" << std::endl;
        }
    }
    
    int main() {
        print(10);    // 输出: Integral: 10
        print(3.14);  // 输出: Floating Point: 3.14
        return 0;
    }
    ```

-   Type lists and their operations
    
    Type lists are manipulated through recursive templates and `std::conditional`.
    
    ```c++
    #include <iostream>
    #include <type_traits>
    
    // 比较两个类型的大小
    template <typename T1, typename T2>
    struct LargerType {
        using type = typename std::conditional<(sizeof(T1) > sizeof(T2)), T1, T2>::type;
    };
    
    // 递归获取最大类型
    template <typename T1, typename T2, typename... Rest>
    struct LargestType {
        using type = typename LargestType<typename LargerType<T1, T2>::type, Rest...>::type;
    };
    
    // 基本情况
    template <typename T>
    struct LargestType<T> {
        using type = T;
    };
    
    int main() {
        using Largest = LargestType<int, double, char>::type;
        std::cout << "Largest type size: " << sizeof(Largest) << std::endl; // 输出: 8 (double)
        return 0;
    }
    ```

-   Static polymorphism (CRTP, the Curiously Recurring Template Pattern)
    
    It implements template-based interface inheritance. Static polymorphism through the CRTP pattern avoids the runtime overhead of virtual functions.

```c++
#include <iostream>

// CRTP 基类
template <typename Derived>
class Base {
public:
    void interface() {
        static_cast<Derived*>(this)->implementation();
    }
};

// 派生类
class Derived : public Base<Derived> {
public:
    void implementation() {
        std::cout << "Derived implementation!" << std::endl;
    }
};

int main() {
    Derived d;
    d.interface(); // 输出: Derived implementation!
    return 0;
}
```

-   Compile-time assertions
    
    Conditions on the code are verified at compile time with facilities such as `static_assert`.
    
    ```c++
    #include <iostream>
    
    template <typename T>
    void checkType() {
        static_assert(std::is_integral<T>::value, "Type must be integral!");
        std::cout << "Type is integral." << std::endl;
    }
    
    int main() {
        checkType<int>();    // 输出: Type is integral.
        // checkType<double>(); // 编译错误: Type must be integral!
        return 0;
    }
    ```
