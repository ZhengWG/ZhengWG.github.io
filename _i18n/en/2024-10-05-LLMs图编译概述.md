## An Overview of Graph Compilation for LLMs

Graph compilation optimization is built around AI compilers. For the overall framework, see [The Deep Learning Compiler: A Comprehensive Survey](https://arxiv.org/pdf/2002.03794):

## Graph Optimization for LLMs

The structure of LLM models themselves changes little, which means that graph-level optimization strategies are fairly general, such as:

fusion of quantization operators, fusion of pointwise operators, and custom fused operators. A common strategy is therefore to reuse the compiler of a framework such as PyTorch and build a custom LLM compiler on top of it, as described in [[RFC] A Graph Optimization System in vLLM using torch.compile](https://docs.google.com/document/d/1CvbJ0LOotlfTjR6RmlQKLO4zcEvN2deoDacSjQ31Xiw/edit?pli=1):

A `User-defined Compiler` is added on top of the `FX Graph` from `TorchDynamo` to implement custom compiler optimization for LLMs. Its advantage is that it can do high-level IR optimization without developing a dedicated compiler, while reusing TorchDynamo's low-level IR optimization capabilities. The drawback is that its input graph is a `raw FX Graph`, so operations such as `code elimination/topo sort` are somewhat difficult to implement.

### Implementing a Custom Compiler on the FX Graph

Here is an example implementation of a custom compiler:

```python
import torch
from torch.fx import GraphModule

def my_custom_compiler(fx_graph: GraphModule, example_inputs):
    """
    自定义 Compiler 接收 FX Graph 并进行处理。
    :param fx_graph: TorchDynamo 捕获的 FX GraphModule。
    :param example_inputs: 示例输入张量，用于形状推导或优化。
    :return: 返回优化后的 callable。
    """
    print("Original FX Graph:")
    print(fx_graph.graph)

    # 对 FX Graph 进行优化或修改，例如插入自定义算子。
    for node in fx_graph.graph.nodes:
        if node.op == 'call_function':
            print(f"Optimizing node: {node.name}, function: {node.target}")
    
    # 可以返回修改后的 GraphModule 或直接生成一个新的函数。
    fx_graph.graph.lint()  # 检查修改后的图是否有效
    fx_graph.recompile()   # 重新编译图以应用更改
    
    # 返回一个可调用的模块
    return fx_graph
```

To register the custom compiler, use TorchDynamo's torch._dynamo.optimize interface to bind it to the target model:

```python
import torch._dynamo as dynamo

# 注册自定义 Compiler
optimized_model = dynamo.optimize(my_custom_compiler)(model)

# 运行优化后的模型
example_inputs = torch.randn(1, 3, 224, 224)  # 示例输入
output = optimized_model(example_inputs)
```

The printed FX Graph is as follows:

```python
graph():
    %x : [#users=1] = placeholder[target=x]  # 输入张量 x
    %linear_weight : [#users=1] = get_attr[target=linear.weight]
    %linear_bias : [#users=1] = get_attr[target=linear.bias]
    %linear_output : [#users=1] = call_function[target=torch.nn.functional.linear](args = (%x, %linear_weight, %linear_bias), kwargs = {})
    %relu_output : [#users=1] = call_function[target=torch.nn.functional.relu](args = (%linear_output,), kwargs = {})
    return relu_output
```
