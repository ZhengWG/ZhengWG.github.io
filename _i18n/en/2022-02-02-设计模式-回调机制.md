# Concept<a id="sec-1"></a>

A callback is the process of passing a function as an argument to another function and deferring its execution to some moment inside that other function. It is essentially an expression of functional programming. If a language only supports object-oriented programming, the Strategy pattern can be used to implement the callback mechanism. Advantages:

-   It avoids duplicated code
-   It improves code maintainability
-   It allows more customization

Disadvantages:

-   You need to avoid "callback hell": calls to multiple nested callback functions

Common scenarios:

-   Third-party libraries and frameworks
-   Asynchronous execution (for example reading files, sending HTTP requests, etc.)

# Design Template<a id="sec-2"></a>

The code framework of the callback mechanism is as follows:

```python
def callback(*args, **kwargs):
    """回调函数"""
    # todo 函数体的实现


def otherFun(fun, *args, **kwargs):
    """高阶函数：也叫包含函数"""
    # todo 函数体的实现


# 函数的调用方式
otherFun(callable)
```

# Example<a id="sec-3"></a>

Scenario: provide asynchronous HTTP download. "Asynchronous" here means that the next task can run before the previous one has finished (and a notification is received once the previous task completes):

```python
import requests
from threading import Thread


class DownloadThread(Thread):
    """下载文件的线程"""

    # 每次写文件的缓存大小
    CHUNK_SIZE = 1024 * 512

    def __init__(self, filename, url, save_path, callback_progress, callback_finished):
        super().__init__()
        self.__filename = filename
        self.__url = url
        self.__save_path = save_path
        self.__callback_progress = callback_progress
        self.__callback_finished = callback_finished

    def run(self):
        readsize = 0
        r = requests.get(self.__url, stream=True)
        totalsize = int(r.headers.get('Content-Length'))
        print("[下载%s]文件大小：%d" % (self.__filename, totalsize))
        with open(self.__save_path, "wb") as file:
            for chunk in r.iter_content(chunk_size = self.CHUNK_SIZE):
                if chunk:
                    file.write(chunk)
                    readsize += self.CHUNK_SIZE
                    self.__callback_progress(self.__filename, readsize, totalsize)
        self.__callback_finished(self.__filename)


def test_download():
    def download_progress(filename, readsize, totalsize):
        # 定义显示下载进度的回调函数
        percent = (readsize / totalsize) * 100
        print("[下载%s] 下载进度:%.2f%%" % (filename, percent))

    def download_finished(filename):
        # 定义下载完成后的回调函数
        print("[下载%s] 文件下载完成!" % filename)

    print("开始下载TestForDownload1.pdf...")
    downloadurl1 = "http://xxxx.pdf"
    download1 = DownloadThread("TestForDownload1", downloadurl1, "./download/1.pdf", download_progress, download_finished)
    download1.start()

    print("开始下载TestForDownload2.pdf...")
    downloadurl2 = "http://yyyy.pdf"
    download2 = DownloadThread("TestForDownload2", downloadurl2, "./download/2.pdf", download_progress, download_finished)
    download2.start()

    print("执行其他的任务...")
```
