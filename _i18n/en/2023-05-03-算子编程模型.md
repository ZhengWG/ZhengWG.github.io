## Kernel Programming Models

### Hardware Characteristics

The hardware used for deep learning today is mainly GPUs and various XPUs (ASICs). The main characteristics of the GPU architecture are:

- Memory architecture: The GPU's on-chip cache is relatively small, and it usually uses high-bandwidth memory such as HBM, with a multi-level memory design.

- Compute units: The GPU has powerful compute units and heavily oversubscribes threads, focusing on massively parallel computing tasks. The compute unit is the GPU SM, and a single SM can support multiple warps in one clock cycle. For the A100, each SM holds 64 warps, or 2048 threads.

### Software Characteristics

The GPU's distinctive hardware design corresponds to its SIMT programming model, whereas traditional CPUs and XPUs use the SIMD programming model. The main differences are:

  - SIMD uses one thread to process one instruction, and the instruction is vectorized, which means a single instruction can operate on multiple addresses, but the width is fixed. For example, a 4-wide 32-bit vector type, vec4, needs data in multiples of 4.
  
    Its advantage is that SIMD performs better on large contiguous data, but for small data, especially data that cannot be kept at an integer multiple of the vector width, some computation is wasted.
  
  - SIMT takes a single-core, multi-thread approach: a single compute unit (SM) supports multiple threads, and multiple threads execute the same instruction, which hides I/O latency through multithreading.
  
    SIMT places lower demands on developers, because instructions are always uniform across threads, and they only need to handle how data is laid out across threads.

### Example

Below is a basic matrix multiplication example, $C = A \times B$:

+ Matrix A has size $M \times K $.
+ Matrix B has size $K \times N $.
+ Matrix C has size $M \times N $.

A SIMD-based implementation, using Ascend C as the example:

```c++
// Ascend C 矩阵乘法 (GEMM) 示例
void gemm_cce(__gm__ float *A, __gm__ float *B, __gm__ float *C, int M, int N, int K) {
    // 定义缓冲区大小
    __ub__ float A_tile[128 * 128];
    __ub__ float B_tile[128 * 128];
    __ub__ float C_tile[128 * 128];

    // 设置 Tile 大小 (块的大小，Ascend 推荐用 32 的倍数)
    const int TILE_M = 128;
    const int TILE_N = 128;
    const int TILE_K = 128;

    // 按块计算矩阵乘法
    for (int m = 0; m < M; m += TILE_M) {
        for (int n = 0; n < N; n += TILE_N) {
            // 初始化 C_tile
            __memset(C_tile, 0, TILE_M * TILE_N * sizeof(float));

            for (int k = 0; k < K; k += TILE_K) {
                // 从 GM 加载 A 和 B 的子块到 UB
                __gm_to_ub(A_tile, A + m * K + k, TILE_M * TILE_K * sizeof(float));
                __gm_to_ub(B_tile, B + k * N + n, TILE_K * TILE_N * sizeof(float));

                // 使用向量化 Tile 计算块级矩阵乘法
                for (int i = 0; i < TILE_M; ++i) {
                    for (int j = 0; j < TILE_N; ++j) {
                        for (int t = 0; t < TILE_K; ++t) {
                            C_tile[i * TILE_N + j] += A_tile[i * TILE_K + t] * B_tile[t * TILE_N + j];
                        }
                    }
                }
            }

            // 将结果写回到 GM 中
            __ub_to_gm(C + m * N + n, C_tile, TILE_M * TILE_N * sizeof(float));
        }
    }
}
```

A SIMT-based implementation, using CUDA as the example:

```c++
#include <cuda_runtime.h>
#include <iostream>

// CUDA 核函数：计算 C[i][j] = sum(A[i][k] * B[k][j])
__global__ void gemm_simt(const float *A, const float *B, float *C, int M, int N, int K) {
    int row = blockIdx.y * blockDim.y + threadIdx.y;  // 当前线程负责的行
    int col = blockIdx.x * blockDim.x + threadIdx.x;  // 当前线程负责的列

    if (row < M && col < N) {
        float value = 0;
        for (int k = 0; k < K; k++) {
            value += A[row * K + k] * B[k * N + col];
        }
        C[row * N + col] = value;
    }
}

int main() {
    // 定义矩阵维度
    int M = 256, N = 256, K = 256;
    size_t size_A = M * K * sizeof(float);
    size_t size_B = K * N * sizeof(float);
    size_t size_C = M * N * sizeof(float);

    // 分配主机内存
    float *h_A = new float[M * K];
    float *h_B = new float[K * N];
    float *h_C = new float[M * N];

    // 初始化矩阵（略）

    // 分配设备内存
    float *d_A, *d_B, *d_C;
    cudaMalloc((void **)&d_A, size_A);
    cudaMalloc((void **)&d_B, size_B);
    cudaMalloc((void **)&d_C, size_C);

    // 数据拷贝到设备
    cudaMemcpy(d_A, h_A, size_A, cudaMemcpyHostToDevice);
    cudaMemcpy(d_B, h_B, size_B, cudaMemcpyHostToDevice);

    // 定义线程和块的维度
    dim3 threadsPerBlock(16, 16);
    dim3 blocksPerGrid((N + threadsPerBlock.x - 1) / threadsPerBlock.x,
                       (M + threadsPerBlock.y - 1) / threadsPerBlock.y);

    // 执行 CUDA 核函数
    gemm_simt<<<blocksPerGrid, threadsPerBlock>>>(d_A, d_B, d_C, M, N, K);

    // 复制结果回主机
    cudaMemcpy(h_C, d_C, size_C, cudaMemcpyDeviceToHost);

    // 检查结果（略）

    // 释放资源
    delete[] h_A;
    delete[] h_B;
    delete[] h_C;
    cudaFree(d_A);
    cudaFree(d_B);
    cudaFree(d_C);

    return 0;
}
```
