概念解析

克隆模式的核心是：通过拷贝自身属性来创建一个新对象，核心方法就是 clone 方法，包括两个步骤：

  • 分配一块新的内存空间给新的对象
  • 拷贝父本对象的所有属性

克隆模式的特点是：

  • 通过内存拷贝的方式进行复制，比new方式创建对象性能更好
  • 可以选用设计浅拷贝和深拷贝
  • 通过clone方式创建，不会执行类的初始化 __init__ 函数

from copy import copy, deepcopy


class Clone:
    "基类"

    def clone(self):
        "浅拷贝方式"
        return copy(self)

    def deepclone(self):
        "深拷贝方式"
        return deepcopy(self)
